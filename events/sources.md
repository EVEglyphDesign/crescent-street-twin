# Sources — Crescent Street events calendar

Compiled 7 August 2026. Every source below was checked for: what it provides, how often it updates, whether it offers a real feed (iCal/RSS/JSON/open-data API), and whether its `robots.txt` permits automated reading. Sources that pass all of these are carried into `scan_targets.json`.

---

## 1. Street-level festivals and closures on Crescent

- [Festival Grand Prix sur Crescent — official site](https://www.crescentgrandprix.com/) — The organiser's own site for the annual Crescent Street Grand Prix Festival (25th edition ran May 21–24, 2026). Publishes exact dates, hours, and a day-by-day DJ/band lineup once the edition is confirmed (typically a few months ahead). Updates seasonally (a few times a year, mostly Feb–May). No iCal/RSS/JSON feed; plain HTML (Squarespace). `robots.txt` blocks a long list of named AI/data-scraper bots (GPTBot, ClaudeBot, CCBot, Amazonbot, etc.) but does not appear to block generic/unnamed user agents — treat as **restricted for AI crawlers, ambiguous for generic bots**; a nightly scan should identify itself and respect the explicit bot list.
- [Festival Grand Prix sur Crescent — FAQ page](https://www.crescentgrandprix.com/faq) — Confirms hours (11:00–23:00) and notes street closures/traffic diversions during the festival. Same update cadence and robots profile as the main site.
- [Global News — Crescent Street Grand Prix Festival 2026 event listing](https://globalnews.ca/event/11822859/crescent-street-grand-prix-festival-2026/) — Secondary confirmation of 2026 dates, attendance estimate, and organiser contact. Global News is a trusted news outlet; standard news-site robots policy (not individually checked, but reputable large media sites generally allow indexing of article pages).
- [Formula1.com — Canadian Grand Prix 2026 official schedule](https://www.formula1.com/en/racing/2026/canada) — Official F1 session schedule (practice, sprint, qualifying, race). Updates once the season calendar is set (roughly a year ahead) and again close to the event. No public iCal/RSS on this page; F1 does not publish an open calendar API for general use.
- [Wikipedia — 2026 Canadian Grand Prix](https://en.wikipedia.org/wiki/2026_Canadian_Grand_Prix) — Encyclopedic summary with race date/time and result. Wikipedia's `robots.txt` is broadly permissive for well-behaved bots (blocks only a short list of abusive crawlers). Not a primary source but reliable for cross-checking.
- [CBC News — Grand Prix weekend traffic survival guide (2018, illustrative of the recurring pattern)](https://www.cbc.ca/news/canada/montreal/your-montreal-grand-prix-weekend-traffic-survival-guide-1.4693716) and [CBC News — Grand Prix mobility/traffic advisory (2023)](https://www.cbc.ca/news/canada/montreal/montreal-grand-prix-mobility-traffic-1.6874737) — Confirm the annual pattern of Crescent Street closure (Ste-Catherine to Sherbrooke) during GP weekend. News articles, not a calendar — useful for confirming the *pattern* but not for pulling exact 2026/2027 hours automatically.
- [CityNews Montreal — street closures ahead of Canadian Grand Prix (2024)](https://montreal.citynews.ca/2024/06/04/street-closures-canadian-grand-prix/) — Same pattern confirmation, most recent detailed report found.
- [Ville de Montréal — "Organize a public event in your borough"](https://montreal.ca/en/how-to/organize-public-event-your-borough) — The city's own permit-application guidance (deadlines, fees, requirements for street closures). This is process documentation, not an events feed, but is the authoritative source on how/when Crescent-area closures get authorized. Part of the montreal.ca site; see robots note below.
- [Ville de Montréal — Événements publics open-data dataset](https://donnees.montreal.ca/dataset/evenements-publics) — **The single most important machine-readable civic source.** CKAN-based open-data catalogue entry with downloadable CSV, GeoJSON, and Shapefile resources, refreshed regularly (metadata showed a same-day update timestamp at compile time). Confirmed via direct download that the CSV contains ~5,300 rows with `titre`, `date_debut`, `date_fin`, `arrondissement`, `adresse_principale`, lat/long, etc. **No row currently mentions "Crescent" by name**, but 635 rows are tagged `arrondissement = Ville-Marie` (the borough containing Crescent St.), so a nightly scan filtering on that column is the best available proxy. CKAN Action API is also available at `https://donnees.montreal.ca/api/3/action/package_show?id=evenements-publics` (JSON). `robots.txt` disallows `/api/`, `/dataset/rate/`, `/revision/`, and `/dataset/*/history`, but did **not** block a direct `package_show` API request or a direct CSV file download in testing (both returned HTTP 200 with a normal user agent) — the disallow lines are likely aimed at the do-not-index HTML rating/history pages, not the API/data endpoints, but a strict nightly scanner should honor the `Disallow: /api/` line and instead poll the static CSV/GeoJSON download URLs, which sit under `/dataset/.../download/...` and are not covered by the disallow rules.
- [Ville de Montréal — official events calendar (montreal.ca/en/events)](https://montreal.ca/en/events) — The human-facing HTML calendar that feeds the open-data export above. Updates daily. `robots.txt` for montreal.ca disallows search-result pages and several *calendar* URL patterns with query strings (`/calendrier-culturel?*`, `/en/arts-and-culture-calendar?*`, etc.) — the plain `/en/events` listing itself is not explicitly disallowed, but paginated/filtered calendar views likely are. Prefer the open-data CSV/API over crawling this HTML calendar.
- [SIM (Service de sécurité incendie de Montréal) — Road closures safety requirements](https://sim.montreal.ca/en/road-closures) — City fire-department rules that apply to any street closure; informational/regulatory, not an events feed.

## 2. Merchant and district associations

- [crescentmontreal.com — Événements / Events page (Crescent Street Merchants Association)](https://www.crescentmontreal.com/evenements-events) — The merchants' association's own events page. Historically used to announce pedestrianization and closures (e.g. the 2020 COVID-era car-free summer). Content appeared stale at compile time (referencing an "until Oct 31" closure from a past year with no 2026 update visible), suggesting **infrequent updates** — this page should be spot-checked rather than relied on as a live feed. Plain HTML (Squarespace-style site), no RSS/iCal/JSON found. `robots.txt` allows `/` generally (blocks only ads-bot admin paths, PetalBot, and sets a crawl-delay for a couple of named SEO bots) — **crawlable**.
- [Wikipedia — Crescent Street](https://en.wikipedia.org/wiki/Crescent_Street) — Background on the Crescent Street Merchants Association (formed 1998), its role organizing the Grand Prix Festival since the early 2000s, and historical notes (e.g. 2019 NBA Finals watch party). Useful context, not a live events source.
- [Ville de Montréal — Regroupements de commerçants à Ville-Marie](https://montreal.ca/articles/regroupements-de-commercants-ville-marie-20731) — Official city page listing recognized merchant associations in Ville-Marie borough, confirming "Association des marchands de la rue Crescent" as a recognized body. Directory/reference page, not an events feed.
- [Tourisme Montréal (mtl.org) — Festivals and events](https://www.mtl.org/en/what-to-do/festivals-and-events) — Tourisme Montréal's official festivals hub; features one flagship event at a time plus a "learn more" link structure rather than a full list/feed. Updates periodically (multiple times per season). No RSS/iCal/JSON found on this page. `robots.txt` is broadly permissive (`Allow: /` with a short disallow list for search/api paths) and publishes a sitemap (`https://www.mtl.org/sitemap.xml`) — **crawlable**, and the sitemap itself could be polled by a scanner for new/updated pages.
- [Montréal centre-ville (Destination Centre-Ville) — Events listing](https://montrealcentreville.ca/en/events/) and [homepage listing](https://montrealcentreville.ca/en/) — Destination Centre-Ville's downtown events aggregator. Confirmed via direct fetch: an HTML listing ("12 events found"), no calendar/RSS/iCal marker found on the page, no stated update frequency. Content observed included Jazz Fest, museum exhibitions, and a weekly Esplanade PVM yoga series — general downtown draws, not Crescent-specific. `robots.txt` only blocks `/wp-admin/` (WordPress) — **broadly crawlable**, but the page itself is not a structured feed, only human-readable HTML with repeated/duplicated listing blocks observed during extraction (likely a front-end template issue on the source site, not a scanner error).

## 3. City-wide festivals reaching downtown / near Crescent

- [Festival International de Jazz de Montréal — official site](https://montrealjazzfest.com/en) — 46th edition, June 25–July 4, 2026 (Quartier des Spectacles). `robots.txt` explicitly allows `/api/search*`, disallows generic `/search`, `/recherche`, `/api/` (except the search path), and `/feeds/` — and separately **fully disallows Bingbot** (`User-Agent: bingbot / Disallow: /`). Publishes sitemaps including a dedicated **events sitemap** (`https://montrealjazzfest.com/sitemap/events.xml`) — this is a genuinely useful machine-readable target: a scanner can poll the events sitemap XML for new/changed event URLs. Government cross-check: [Canada.ca — 46th Festival International de Jazz de Montréal](https://www.canada.ca/en/canadian-heritage/news/2026/06/government-of-canada-supports-the-46th-festival-international-de-jazz-de-montreal.html).
- [Francos de Montréal — official site](https://francosmontreal.com/en) — 37th edition, June 12–20, 2026 (pre-opening show June 11 at Bell Centre). Same robots/sitemap pattern as the Jazz Festival (same platform vendor): allows `/api/search*`, disallows Bingbot entirely, publishes an **events sitemap** (`https://francosmontreal.com/sitemap/events.xml`).
- [Just for Laughs / Juste pour rire — official dates announcement](https://www.hahaha.com/page/detail/news/juste-pour-rire--just-for-laughs-quebec--announces-2026-festival-dates-74/) — Montréal edition July 15–26, 2026. `robots.txt` for hahaha.com is fully permissive (`Allow: /`). No feed format identified on this specific announcement page; the main hahaha.com site should be checked separately for a programme/calendar page format.
- [Osheaga — official site](https://osheaga.com/en) and [schedule page](https://osheaga.com/en/program/schedule) — July 31–Aug 2, 2026, Parc Jean-Drapeau. Same platform/robots pattern as Jazz Fest/Francos (allows `/api/search*`, disallows Bingbot, publishes an events sitemap at `https://osheaga.com/sitemap/events.xml`).
- [Montréal en Lumière — Nuit Blanche page](https://montrealenlumiere.com/en/experience-nuit-blanche) — 23rd Nuit Blanche edition, Feb 28–Mar 1, 2026 (already past for the remainder-of-2026 scan window; 2027 edition not yet announced). Same platform/robots pattern as the above three festivals (events sitemap at `https://montrealenlumiere.com/sitemap/events.xml`).
- [Fierté Montréal — official homepage](https://fiertemontreal.com/en) and [Visitor Info page](https://fiertemontreal.com/en/festival-2026/visitor-info-2) and [Pride Parade page](https://fiertemontreal.com/en/festival-2026/pride-parade) — Festival July 31–Aug 9, 2026; Pride Parade Aug 9, 2026, 13:00, on René-Lévesque Blvd. `robots.txt` is fully permissive (`Allow: /`) and publishes a sitemap (`https://fiertemontreal.com/sitemap.xml`). Note: several third-party aggregators (e.g. cglq.ca) list a conflicting Aug 16, 2026 parade date — **do not trust those**; the official organiser site is unambiguous about Aug 9.
- [NHL.com — Montréal Canadiens official schedule](https://www.nhl.com/canadiens/schedule) — Full 2026-27 season schedule including all Bell Centre home dates through year-end. `robots.txt` allows `/` broadly (blocks only asset/utility paths and `/search`) and publishes a sitemap index (`https://www.nhl.com/sitemap/sitemap-index.xml`). The NHL also has a documented public **schedule API** (`api-web.nhle.com`, used by many third-party schedule sites) though it was not directly queried here — flagging it as a strong candidate for `scan_targets.json` follow-up if JSON access is confirmed.
- [Centre Bell (Bell Centre) — official venue site](https://centrebell.ca/en) — Concert/event calendar for the arena itself (a few blocks from Crescent). Same platform pattern as the festival sites above: allows `/api/search*`, disallows generic search/recherche, publishes sitemaps (`https://centrebell.ca/sitemap.xml`, `https://centrebell.ca/sitemap/pages.xml`) — no dedicated events sitemap was found for this domain (unlike the festival sites), so the general sitemap is the best available crawl target.
- [Tourisme Montréal (mtl.org) — UCI Road World Championships Montréal 2026 feature](https://www.mtl.org/en/what-to-do/festivals-and-events) — Sept 20–27, 2026, downtown road-race circuit. Featured-event card only; no detailed route/closure page found yet.

## 4. Recurring weekly programming at the six Crescent Street venues

- [Hurley's Irish Pub — official site](https://www.hurleysirishpub.com/) — Confirms live music **every night of the week**, but does not publish nightly showtimes, band names, or a forward calendar. A `/live-music` subpage was tested and returned an error (page not found) at compile time. `robots.txt` request returned a generic 404 HTML page rather than a real robots file — in the absence of a robots.txt, standard practice treats the site as **crawlable by default**, but there is effectively nothing structured to crawl beyond the static homepage claim.
- [Brutopia — official site](https://www.brutopia.net/) — **Best-documented venue calendar of the six.** Publishes a genuine day-by-day entertainment table (verified sample spanning Jan–Mar 2026): Wed/Thu/Fri/Sat = named live bands with a site-wide stated showtime of **22:00 nightly**; every Sunday = "Open Mike" with a rotating host; every Monday = "Joey's Happy Hour Monday Madness Trivia." `robots.txt` explicitly allows crawling and even sets `Content-Signal: search=yes, ai-input=yes, ai-train=yes` — the most scan-friendly source in this whole dataset. Publishes a sitemap (`https://www.brutopia.net/sitemap.xml`). No iCal/RSS/JSON found — it is an HTML calendar table, but the explicit AI/search permission signal and clean weekly structure make it an excellent nightly-scan target via HTML parsing.
- [Sir Winston Churchill Pub Complexe — official site](https://www.swcpc.com/) — Publishes a **daily** Happy Hour (17:00–19:00) explicitly. Mentions DJ nights (House/Pop/Top 40) and "various comedy shows" but with no day/time specificity anywhere on the site. `robots.txt` request returned an empty body with HTTP 301 (redirect) — no explicit disallow rules found, treated as **crawlable by default**, though the redirect behaviour should be followed by any scanner.
- [Ziggy's Pub — official site](https://ziggyspub.ca/) — Publishes only address and hours (13:00–03:00). **No recurring programming of any kind is published** — confirmed gap, not a search miss. `robots.txt` disallows only `/404` — otherwise crawlable, but there is nothing to extract beyond static hours.
- [Wienstein & Gavino's — official site](https://www.wgmtl.com/) — Publishes only hours and menu. **No recurring programming published.** `robots.txt` (Wix-generated) allows `/` generally, blocks a couple of technical paths and the PetalBot crawler, and publishes sitemaps (`https://www.wgmtl.com/sitemap.xml`, `https://www.wgmtl.com/fr_fr-sitemap.xml`) — crawlable, but again nothing structured to extract for events specifically.
- [The Brass Door Pub — brassdoor.pub](https://brassdoor.pub/) — This domain **redirects to the venue's Instagram profile** rather than hosting an independent website. `robots.txt` request returned an empty body with HTTP 200 (no disallow rules), but the destination content is an Instagram page, which requires a logged-in session / JavaScript rendering and is not realistically machine-readable by a simple nightly scanner without using Instagram's own (heavily gated) API. This is the weakest source of the six venues.

### Summary of feed availability across all sources

| Source | Feed type | Robots status |
|---|---|---|
| Ville de Montréal open-data (Événements publics) | CSV / GeoJSON / SHP / CKAN JSON API | Permits data downloads; disallows `/api/` path generally, but `package_show` and CSV download URLs responded normally in testing |
| Montréal Jazz Fest / Francos / Osheaga / Montréal en Lumière | Events XML sitemap | Allowed for generic bots; explicitly blocks Bingbot |
| Brutopia | HTML calendar table (no formal feed) | Explicitly AI/search-crawl-friendly (`Content-Signal` header) |
| Fierté Montréal, mtl.org, NHL.com, Centre Bell | XML sitemap | Broadly permissive |
| crescentgrandprix.com | HTML only | Blocks named AI/scraper bots specifically |
| Sir Winston Churchill, Hurley's, Ziggy's, Wienstein & Gavino's, Brass Door (Instagram) | HTML only, no feed | No explicit disallow found, but little/no structured content to extract |
